Функция visibleSat определяет радиовидимость GPS спутников относительно LEO спутника.
Функция getEphemeris возвращает ближайшие по времени эфемериды GPS спутников из Rinex файла
Функция calcGpsTime вычисляет для заданного момента время число секунд от начала текущей недели GPS
Функция calcGpsCoordinates вычисляет для заданного момента время текущие координаты всех GPS спутников для заданных эфемерид
Функция calcLeoCoordinates вычисляет для заданного момента время текущие координаты LEO спутника для заданных параметров орбиты
Функция calcGMST вычисляет текущее Гринвичское звездное время
